# Hedef kitle personası — Sosyal Pediatri klinisyen jürisi

**Kim:** Çocuk sağlığı ve hastalıkları / sosyal pediatri öğretim üyeleri. Klinisyen kökenli;
klinik epidemiyoloji ve temel istatistiğe aşina; **psikometri, davranış bilimi ölçüm kuramı ve
ileri nedensel/Bayes/gizil-değişken metodolojilerinde derin altyapıları yok.** Metni ilk
okuyuşta, geri dönüp jargon çözmeden anlamalılar.

## Bilir — çeviri gerekmez, bu zeminde konuş

Prevalans/insidans · ortalama ± SS · medyan / çeyrekler arası aralık (ÇAA) · p-değeri (kabaca
"şans eseri olma olasılığı") · duyarlılık/özgüllük · OR / RR · güven aralığı (kabaca) · tanı
ölçütü mantığı · klinik göstergeler · karıştırıcı (confounding) kavramı (klinik
epidemiyolojiden tanıdık).

## Çevrilmeli — ilk geçişte klinik karşılık + parantezde özgün ad

| Terim | Klinisyen karşılığı (ilk geçiş glossu) |
|---|---|
| SMD (standardize ortalama fark) | iki grup farkının ortak cetvele vurulmuş hâli; sıfıra yakın = benzer (etki-büyüklüğü gibi) |
| latent SES kompoziti | eğitim+meslek+maddi göstergeyi tek bir gizli "sosyoekonomik düzey" ölçüsünde birleştirme |
| eğilim skoru (propensity) | bir ailenin ilgili gruba (ör. DM) düşme olasılığı; gözlemsel veriyi dengelemek için |
| IPTW (ters-olasılık ağırlıklandırma) | eğilim skoruna göre ağırlık verip grupları "sanki denk dağıtılmış gibi" kıyaslanır kılma |
| ortak destek (common support) | grupların örtüştüğü, gerçekten karşılaştırılabilir olduğu aralık |
| yönlü asiklik graf (DAG) | değişkenler arası neden-sonuç yönlerini gösteren ok şeması; hangi karıştırıcının düzeltileceğini belirler |
| ICC (sınıf-içi korelasyon) | aynı aileden ölçümlerin ne kadar benzediği; aile-içi bağımlılık ("kardeşler bağımsız değil") |
| çok düzeyli model | iç içe veriyi (çocuk-içinde-aile) aile-içi benzerliği hesaba katarak analiz eden model |
| Cronbach α / McDonald ω | ölçek maddelerinin aynı şeyi ne kadar tutarlı ölçtüğü (ölçeğin güvenilirliği) |
| CFA / SEM | gözlenen sorulardan gizli bir kavramı (ör. reddedilme algısı) ölçen + kavramlar arası ilişkiyi test eden model |
| uyum indeksi (CFI/RMSEA) | modelin veriye ne kadar uyduğunu özetleyen not (gelenek eşikleri, yasa değil) |
| ölçüm değişmezliği (invariance) | aynı ölçeğin farklı gruplarda aynı şeyi ölçtüğünün kanıtı; olmadan grup kıyası yanıltıcı |
| IRT / GRM | her sorunun zorluk + ayırt ediciliğini modelleyen ölçüm yaklaşımı |
| LPA / LCA (gizil profil/sınıf) | bireyleri gözlenmeyen alt-gruplara (profillere) ayırma; "veriden fenotip çıkarma" gibi |
| bifaktör | bir genel faktör + ondan bağımsız özgül faktörleri aynı anda modelleme |
| APIM / diyadik (Olsen–Kenny) | çift verisinde kişinin kendi ve partnerinin etkisini ayıran model |
| Bland–Altman | iki ölçümün/bildirenin mutlak uyumu (fark ± sınırlar); yüksek korelasyon ≠ uyum |
| Bayes faktörü (BF) / ROPE | verinin hangi hipotezi ne kadar desteklediğinin oranı / pratik-olarak-sıfır bandı |
| multiverse / spesifikasyon eğrisi | makul tüm analiz seçeneklerini birden koşup sonucun sağlamlığını görme |
| E-değeri | gözlenen ilişkiyi silmek için ölçülmemiş bir karıştırıcının ne kadar güçlü olması gerektiği (sağlamlık) |
| TOST / eşdeğerlik | "fark yok"u değil "fark önemsiz küçük"ü test eden yaklaşım |
| FIML / çoklu atama (MI) | eksik veriyi silmeden, tüm bilgiyi kullanarak analiz etme |
| AUC / kalibrasyon / DCA | risk modelinin ayırt ediciliği / tahmin doğruluğu / klinik yararı (optimizm-düzeltilmiş = aşırı-iyimserlikten arındırılmış) |
| GGM / ağ / merkeziyet | değişkenleri düğüm, ilişkileri kenar yapan ağ; merkezî düğüm en bağlantılı |
| FDR | çok sayıda test yapınca yanlış-pozitifleri kontrol eden düzeltme |

## Kurallar
- **Tek indekse indirgeme:** eşiği verirken "gelenek, yasa değil" diye çerçevele (kaynağı
  data-narrative `buyukluk-esikleri.md`).
- **Çeviri ≠ mutasyon:** glossla açıkla ama BU sonucun büyüklük/yön etiketini kaynakta yoksa
  ekleme (F1/F2).
- **Tablo büyür:** pasajda bu tabloda olmayan bir terim çıkarsa, klinik karşılığını üret,
  kullan ve **backlog'a ekle** (tez-geneli tutarlılık için tek karşılık).
